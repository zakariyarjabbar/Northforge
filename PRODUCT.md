# NORTHFORGE GROUP

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Next.js App Router, TypeScript, static export, as explicitly requested. No backend, database, accounts, hosted form service, or runtime server.

## Users
Project owners, developers, public authorities, and industrial clients assessing an infrastructure delivery partner. Engineering partners and prospective employees are secondary audiences.

## Product Purpose
A complete agency portfolio website for a fictional international engineering group. The user explicitly delegates creative and implementation decisions and requests a finished company presentation with no public mock-data, demo, or view-only notices. This latest instruction supersedes those notices in the supplied brief.

## Positioning
NORTHFORGE plans, engineers, builds, and maintains transport, marine, industrial, water, and energy infrastructure. Core journey: understand the company, find expertise, inspect a project, prepare an inquiry.

## Capabilities and Constraints
Eight internally consistent project case studies, four expertise detail pages, project discovery with URL filters, accessible geographic explorer, group, careers with three opportunities, contact review/save/edit/export/print flow, saved projects, accurate privacy and browser-data controls, 404 recovery. Public content is typed and bundled. Visitor state stays in versioned browser storage, with validation and memory fallback. Never claim an inquiry was transmitted. No invented clients, accreditations, awards, measured performance, phone numbers, or real street addresses. Generated original industrial imagery with documented provenance.

## Brand Commitments
Name NORTHFORGE GROUP. Capable, precise, grounded, confident, internationally minded. Photography leads; concise edited English. User grants full creative ownership, no design approval checkpoints.

## Evidence on Hand
The supplied complete project brief is the authoritative scope. Project identities, locations, dates, and specifications are authored fictional portfolio content, documented internally. No real commissions, clients, or executive biographies are supplied.

## Product Principles
- Every visible action and destination must be complete.
- Prefer useful scope and engineering detail to corporate statistics.
- Keep primary journeys familiar, with ambitious presentation.
- Describe browser storage and actions accurately without labeling the public site a demonstration.

## Accessibility & Inclusion
Aim for WCAG 2.2 AA; keyboard and touch equivalence, readable text, visible focus, accessible errors, reduced motion, and robust responsive layouts. Verify behavior rather than claim certification.

## Acceptance
All static routes build and load directly; local data survives reload where storage works; no unfinished public notices; coherent imagery and metadata; functional search/filter/save/inquiry/career/reset workflows; desktop and mobile inspection; documented validation and deployment origin.
